# Third-party tools (not the submission)

DriftZero's original work is the dead-reckoning engine: sensor contracts, the causal filter, and confidence states.
MapLibre Native plus OpenStreetMap/OpenFreeMap tiles are verified OSS used to draw streets. This is not the Google Maps SDK.
Cursor skills from ibelick/ui-skills and emilkowalski/skills are agent UX guidance only. They are not shipped as a web UI kit.
The Android chrome (search, puck, GPS chip) is Compose written for this navigator.
Contest IDs stay out of the driver-facing chrome. Attribution lives here and in `.cursor/skills/`.
