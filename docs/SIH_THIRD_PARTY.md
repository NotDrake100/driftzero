# Third-party tools (not the submission)

DriftZero's original work is the dead-reckoning engine: sensor contracts, the causal filter, and confidence states.

MapLibre Native plus OpenStreetMap and OpenFreeMap tiles draw streets. This is not the Google Maps SDK. Photon, Nominatim, and public OSRM are hosted search and route APIs used until a local pack replaces tiles. Legal text and OSM/ODbL notes live in [NOTICE.md](../NOTICE.md). Do not copy that notice here.

IBM Plex fonts ship under the SIL Open Font License 1.1 (`apps/android/third_party/ibm-plex/LICENSE.txt`).

The Android chrome (search, puck, GPS chip) is Compose written for this navigator. Contest IDs stay out of the driver-facing chrome.

Cursor agent skill files under `.cursor/skills/` are local editor tooling. They are gitignored and are not a shipped UI kit.
